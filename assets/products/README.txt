Product photos for the pop-up product view.

Each product has its own folder, named after its link (sridevjewels.in/#p/<folder name>).
Inside are the photos shown in the pop-up, in order: 1.webp is the first photo.

To use a real photo, replace the file with one of the same name (1.webp, 2.webp ...).
Square or portrait photos about 1200 px wide look best. JPG works too: save it as .webp
or ask for the code to point at the .jpg instead.

To show a different number of photos, change "photos" for that product in products.js.
Names, descriptions and what each set includes are also in products.js.
